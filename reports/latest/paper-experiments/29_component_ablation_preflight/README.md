## 下一轮具体内容

固定热点3271、迁移热点3272、均匀随机3273，各比较Full、CallerOnly、Independent、PoolSIEVE1，共12次。所有版本同总磁盘容量、同暂存上限及共享读取能力，两个消融各只改变一个开关。

每条件只有一组配对，只能开发筛选。没有关闭热点或暂存共享的版本，不能据此结束新版热点独立验证，也不能证明此前随机对旧版的p99退化已经消失。

同机三个逻辑域没有GPU拓扑差异，目前位置选择主要依赖容量和淘汰损失。因此检验的是共享感知副本放置，不能声称物理GPU亲和或真实推理提速。
