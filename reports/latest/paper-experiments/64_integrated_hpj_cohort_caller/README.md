## 改动与实验边界

本次保留现有热点、亲和和联合决策参数，修复三个公共路径上的额外同步写入：首次发现文件与第一次读取计数在同一个 FULL-WAL 事务中提交；成功后台任务的统计与完成标记在同一个事务中提交；调用者识别的辅助计数并入已有持久化统计提交。真实调用者身份仍逐次读取，读取计数、缓存元数据与完整复制校验未放松。五版本共用这些修复，不能将公共优化本身当成某项策略的新贡献。

硬件核验确认 cn7、cn8 是物理主机，但当前系统未发现可用计算 GPU。用户已明确选择继续 cn7 上三个逻辑消费域的小规模验证；cn13 为真实 NVMe/TCP 远端存储，cn8 不参与本批。逻辑消费者串行回放，不代表物理多 GPU 并行、NVLink 或端到端推理。

同一 moving3293 输入，每版本576条2MiB请求，总磁盘缓存24MiB，共享捕获内存4MiB（含在用缓存）。两轮五版本顺序完全相反，共10次测速、5,760条请求。前台本地与远端读取均使用 O_DIRECT，未控制 cn13 操作系统缓存。每次速率为实际完成的逻辑读取字节÷任务墙钟时间，p99使用全部请求响应时间的最近秩定义，无慢请求剔除、无选择性补跑。

本次另两批各10次测速完整保留：报告62仅1/8项双指标通过；报告63为7/8项通过，其中0.263%的p99回退仍判失败。本报告64为同一最终二进制的完整10次运行，没有拼接此前各候选的最好成绩。报告61的两组带遥测诊断不参与速率结论；一个离线先验原型未进行服务器测速。

## 如何用于论文

本批证据支持：在当前移动热点输入和已注明的逻辑域存储环境中，三个模块各自带来吞吐与p99的边际改善，完整方案也优于共享SIEVE。不能据此宣称三项机制具有统计显著性、所有负载都更好或真实GPU已验证。

第二轮部分p99改善不足1%，最小为约0.291%，仍可能受运行波动影响。两轮是同一个参与开发调试的输入；按照本次“双轮正向”的判据已通过，但这不等于独立复现或普遍稳定性。固定热点、均匀随机未在本最终二进制重测，历史结果不能直接代替新版本验证。当前先冻结这份结果，不自行扩大实验规模。
