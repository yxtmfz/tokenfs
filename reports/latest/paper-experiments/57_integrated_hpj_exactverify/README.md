# 移动热点：精确读回校验修复后的四张表

本轮5组探针定位＋10组无探针测速，另有480次SHA256内容检查。测速只有移动热点3293，相同576条请求、2MiB对象、24MiB磁盘和4MiB共享捕获预算，五个版本先倒序后正序。每轮从空项目缓存开始；同一二进制，同一Full用于所有比较，前三张只关闭一个模块。

固定热点保留为稳定负载对照，均匀随机保留为不可预测边界；本轮未重测这两个负载，不能把旧二进制的结果当作此版验证。此前全部数据保留在报告55。

修复：源捕获已完整且不可变时，完整读回复制目标并逐字节比较，检查大小与目标身份未变、源身份仍有效；其余复制继续原有校验。所有版本共用，容量、持久化和策略公式不变。这是执行优化，不单列新创新。

## 本轮结论与下一步

未达标，保持为开发候选；不得用其替换报告55后宣称全场景获胜。亲和与联合准入两轮吞吐为正，但第一轮p99分别增加1.474%和0.496%。热点项两轮吞吐均负，整体对SIEVE方向反转。

原始计数显示，Full两轮均远端读取122MiB、复制27次、淘汰15次；NoHotspot均122MiB、复制26次、淘汰14次；NoAffinity远端读取148/150MiB；NoJoint均130MiB；SIEVE均104MiB、复制52次。热点估值在此输入上没有额外降低远端流量；不能简单归因于测量噪声。NoHotspot仍含近期频率窗口，因此该消融检验的是额外时变估值是否优于已有近期频率，并非检验有无缓存或有无一切热点能力。

本轮Full剩余复制成本均值为5.36/3.61ms；旧探针版的复制阶段约21ms。两者来自不同运行且后一组关闭探针，只能作方向性诊断，不能据此宣称严格的单项加速比例。

后续优先用可观测的重复运行间隔检查时变估值的预测误差、重复衰减与最近频率之间的作用重叠，再做固定输入的小规模配对验证。先保留所有负值，不通过挑种子、删对照或更改通过条件解决问题。固定/均匀新二进制尚未复测，物理GPU尚未验证。
