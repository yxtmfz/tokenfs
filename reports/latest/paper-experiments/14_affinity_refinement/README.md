## 旧版本为什么退化

上一轮的访问者迁移中，旧门槛每轮平均触发 55.75 次，远端读取从无亲和的 176.33 MiB 增至 285.33 MiB，复制量从 25.00 MiB 到 26.83 MiB。旧门槛没有带来对应的复制节省。按原始 trace 因果重放，每轮平均 100.5 次热点访问不满足相对份额门槛；这是潜在门槛拒绝，不等于实际缓存未命中次数。原始计账和重放摘要见 provenance/affinity-v2-root-cause.json。

1. 相对门槛要求本域访问达到最热域的一半。它把“其他域更热”误当作“当前域不值得缓存”；新域已有可偿还复制成本的复用也会被拒绝。
2. 迁移时，旧域的历史计数还在，导致新域需要追赶旧热度；这与实际访问者已经变化不一致。
3. 基础估计采用每域独立的请求窗口；域闲置时窗口不前进，旧副本可能被持续高估。此问题通过独立的闲置后返回回归用例与新场景检验，不把它冒充上一轮唯一退化原因。

## 本次改动与控制变量

取消相对热度的一票否决，改为**访问域切换时的跨域复用借用**。只有当前域占最近四次访问至少三次、该份额至少为长窗口份额的两倍，且当前对象在长窗口内已有至少八次访问、其他域对该对象的计数至少为本域两倍时，才用对象总需求乘近期目的域份额估计新副本复用。取此估计与原域内估计的较大值，对当前请求候选与符合条件的驻留副本使用同一估计，避免新副本刚迁入后被低估而再次淘汰；域内历史计数已归零的对象不借用全球历史，保留热点重置与老化效果。借用证据在一个全局亲和窗口内线性衰减，避免短窗口检测停止时估值突降；只有新的交接证据可刷新预测，过期即失效。复制成本、联合淘汰损失、容量和执行时重检均保留，没有按未来请求或阶段标签决策，也没有主动预取。

P-new 与 P-off 只差 `measured_affinity_gate`，两组都收集相同亲和历史、选择同一估计模式。H 热点适应、J 联合准入、访问路径、缓存配额和后台能力完全相同。P-old 使用保留的旧份额门槛，三组在同一新二进制下重跑；不跨轮相减速度，也不将旧版反例删除。

新版相对旧版在访问者迁移的配对吞吐变化为 +12.35%（确认提速）。是否存在独立贡献仍以表中 P-new/P-off 为准；单纯修复旧版退化不足以证明贡献。

## 测量和证据边界

- cn7 为客户端，远端是 cn13 上原有独立 NVMe/TCP namespace；cn8 仅作独立目录后端内容校验。三个私有逻辑域共用同一物理客户端磁盘，未命中实际读远端，无注入延迟。
- 八场景 × 三策略 × 十二配对种子 1801–1812。六个原场景保留，新增域闲置后返回：四阶段调用域为 0、1、2、0，返回时使用不同六对象热点集合，容量为四对象。另补充八阶段的热点跨域交接：相邻两阶段保持同一四对象热点而切换访问域，后续接收域已存有另一组热点。补充发生于开发阶段，正式样本尚未访问；原七场景全部保留。策略看不到阶段标签。
- 每轮读取 768 MiB，每域配额 8 MiB。前台本地/远端均 O_DIRECT，后台复制 buffered；空应用缓存、随机策略/区块顺序，目标缓存和其他共享任务不受控。
- 12 个公开 toolagent 窗口与 B3、上一轮及本轮彼此不重叠，位于开发前缀之外。调用域按原请求索引模 3 构造，保持对象身份与次序，块大小归一化，串行饱和回放。
- 计时采用客户端 monotonic 外层前台耗时。另报等待用户态队列排空的时间，不等于持久化全部物理写回。服务器 UTC 未同步，不用跨机器日期计算耗时。
- 5000 次配对 bootstrap 区间、精确双侧符号翻转检验（零假设下配对对数耗时差对称）。主比较与旧版修复各作八项 Holm 校正；区间自身未作多重校正。至少 5% 耗时降低是预定实际收益目标，不是保证。
- 初版按统一窗口降低全部候选/旧副本计数，在开发集上收益不足且存在回退，因此未进入正式测试。第二版 B 只给迁入对象借用复用证据，在补充交接场景中比关闭亲和慢 7.05%，每轮复制从 64 MiB 增至 116 MiB，因此也否决。C 统一迁入与驻留对象的估计，但交接场景仍慢 2.28%；检测器停止时借用估计仍会突降。最终 D 对借用证据逐步衰减，并保留 A/B/C 全部原始数据及独立审计。固定开发种子 1701/1702 用于这些开发迭代，与确认种子分离。开发后冻结版本，正式数据不用于再次调参、追加样本或删除负结果。最终版本 48 项内容验证和 48 次开发测速不混入 288 次正式统计。

本次未重测完整策略对 LRU/LFU/RecentLFU 的整体矩阵，不能把本轮亲和收益与上一轮的组件百分比相加。

这是**逻辑访问亲和需求估计对真实存储速度的影响**，不是 PCIe/NVLink 亲和、真实多 GPU 推理、TTFT 或 tokens/s 的证明。完整控制器和整体策略是否优于所有缓存基线也不属于本次三组实验的结论。
