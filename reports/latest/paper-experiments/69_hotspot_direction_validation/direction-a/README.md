# 方向 A：驻留窗口缩放，未采纳

基于报告68的 residual 模型，在每个请求前累加当前驻留对象数作为对象驻留暴露量；发生过淘汰后，以暴露量/(已发生淘汰次数+1)估计窗口，并将预测乘以 min(1,窗口/128)。只使用历史前缀，不读未来。固定21/10.5/8 ms成本、瞬时复制和两对象理想RAM；无服务器测速，无实际吞吐或p99。

八条已使用输入、每条四臂的完整结果见 screen.json。移动73501、73503、公开73601、73602的Full比基础频率同时多远端读取、多复制，未采纳。该结果只否定本次简单缩放的推进价值，不代表所有驻留时间建模都无效。

运行 `python3 replay.py` 可编译并精确复现32个模型臂。setter仅用于串行模型，不是线程安全的生产接口。归档原型没有接入TokenFS，未上传服务器。
