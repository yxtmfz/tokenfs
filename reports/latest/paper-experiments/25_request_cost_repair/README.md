本次共 **18组开发试验**：报告24的12组新旧读填充对照，加报告25的6组成本计量修复验证。没有进入大规模实验，没有替换失败种子。所有数据均为cn7客户端、既有cn13 NVMe/TCP远端、逻辑消费者的存储实测。

**当前结论：修正版对SIEVE-2hit同时取得吞吐和p99优势；对SIEVE-1hit的p99改善，但吞吐仍一胜一负、平均略慢。不能说“所有问题解决”或“全面跑赢SIEVE”，不适合现在据此启动大规模确认。**

## 已完成的实际修复

1. **前台/后台重复取源。** 完整的顺序前台读取现在可以供后台缓存填充复用；目标文件仍重新读取并校验。未读完、乱序、源身份改变、内存不足均走受控回退。READY、配额、打开句柄保护和持久化不放宽。最新6组所有缓存复制都复用了读取数据。额外暂存峰值：完整版3241为4MiB，其余运行2MiB；这不是零内存成本，也不表示物理盘/网络流量归零。
2. **FUSE小尾块使成本估计失真。** 旧代码把每个回调的“耗时/字节”等权更新；1048528字节与48字节的分片可使估计严重偏离整个请求。原生反例能重现本地整体更快却被判断为更慢。现在一次逻辑读取累计实际字节与耗时，再生成一个成本样本；不删除慢样本或人为指定带宽。最新6组的3456次逻辑读取都对应一个样本，分层字节精确匹配读取计数。
3. **最终决策计数快照不完整。** 报告24一组运行有7项后台决策指标在报告写出后才刷入SQLite。采集端现在等进程退出后取最终指标，验证请求/字节/后台完成计数不变，保留原始计时。报告25全量指标与最终SQLite完全一致。没有为此增加运行路径的fsync或改变数据库持久化。
4. **复制/重命名失败码被清理覆盖。** 保存原始错误码后再清理临时文件，避免清理成功掩盖真实错误。

这些改动默认按配置启用，最新实验明确设置foreground_read_fill=true、request_read_costs=true；不要用旧配置直接推定已经启用新路径。

## 尚未解决的强基线差距，有什么直接证据

|种子|完整版远端读 MiB|1hit远端读 MiB|完整版复制次数|1hit复制次数|完整版执行前copy_cost拒绝次数|
|---|---:|---:|---:|---:|---:|
|3241|346|216|43|54|25|
|3242|192|220|48|55|0|

在失败的3241种子，完整版少做11次复制，却多读130MiB远端数据，相当于65次额外2MiB远端请求；另有25次执行前的复制成本复核拒绝。当前联合决策的省复制取舍没有换来更快的总吞吐。这支持继续检查准入及执行时机，不能把剩余差距仅归咎于随机噪声或CPU控制开销。

SHARED_PLACE与实际ADMIT之间可能已有下一次访问到达，剩余连续复用预测随之下降。复制是异步的，全段复制耗时也不等于全部增加在前台响应上的耗时。因此下一步应研究“缓存何时可用、还有多少可受益访问、复制增加多少前台阻塞”的一致成本模型，而不是简单降低代价权重或关闭安全复核来获得好看的数字。

**这个联合决策模型调整尚未实施，也没有新性能结果。** 要保留配额/受害者/句柄的执行时复核，先以确定性并发时序测试覆盖“下一读已发出”的边界；之后再用极小的同版本旧/新联合控制器与两个强基线对照验证。当前不追加大规模运行。

## 失败过程保留，不拼接版本

报告24初版读填充：SIEVE-1hit/2hit新旧路径配对分别+12.92%/+9.34%，但完整版一组从118.57降到86.24MiB/s，完整版新旧配对−10.65%。该失败促成了计量修复，全部12组证据保留。

报告24的严格最终指标一致性检查仍明确为失败（7项非I/O决策统计快照差异），计时、请求、读取字节、复制、容量及内容关键检查通过。报告25修复此问题并通过全量审计，不能反向改写报告24的原始JSON。

报告25使用新种子3241/3242，没有同种子的旧估计器运行；不能把86.24与133.29直接相除声称修复提速54%。旧版本H/P/J收益也不能作为当前版本的消融结果。

## 当前能支持及不能支持的论文结论

- 能支持：存在可复现的小分片计量错误；前台读取复用在相同策略下可带来真实吞吐和p99改善（报告24两个SIEVE成对对照）；最新完整系统在当前两个热点种子上优于同路径SIEVE-2hit，并在p99上优于两种SIEVE。
- 尚不支持：稳定全面优于共享SIEVE-1hit；热点、亲和、联合三个模块在最新版本各自都有独立增益；均匀随机及真实轨迹的鲁棒性；真实多GPU KV共享或LLM端到端加速；论文创新性或期刊分区保证。
- Read-fill是三种策略共享的执行优化，其共同收益不能独占为亲和策略的创新证明。当前仍未达到启动大规模确认或宣布论文实验闭环的条件。
