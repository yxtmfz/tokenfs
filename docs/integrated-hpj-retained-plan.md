Common observation, cost calibration, physical execution, exploration, buffers and durability remain in the ablations.

Prior evidence showed policy-dependent transient memory lifetime: an admitted copy kept a capture alive while rejected or finished work lost it. Introduce opt-in retain_read_fill identically for every arm. Complete immutable captures enter a shared LRU under the EXISTING4MiB combined budget. Reader/copy pins remain charged and cannot be evicted; new capture fails when all space is pinned. Incomplete or stale captures never become readable. After copy completion or admission rejection, valid retained bytes remain equally readable. The legacy inflight counter now denotes all captured-memory reads; retained_capture_hit separately identifies this mode. It must not be described as pending-copy reads.

The same flag tells every measured-policy arm that adjacent burst reads are served by retained memory: BurstRemaining contributes no additional DISK-placement value, and both temporal and static estimated repeat counts are scaled by completed-run average length. This estimates marginal disk benefit; no current-run future length is used. The predictor is heuristic and assumes observed sequential clustering, not guaranteed concurrent GPU behavior. SIEVE needs no benefit estimator but has identical buffer ability.
